首頁平均怎麼算？

先在每個分項內對所有題目取平均，再把 MLQA 三方向、ACORD、MIRACL 中英文共六個分項的分數相加除以六。每分項各占 16.67%；按資料家族看，MLQA 占 50%、MIRACL 占 33.33%、ACORD 占 16.67%，不是三個家族等權。僅比較六分項皆有測量的三種 Qwen 4B embedding 組合；缺測不補零，也不以不同分母排名。MLQA 平均則是三方向各占 1/3，包含六種配置。

Top-1 與 nDCG 回答不同問題

Top-1 是第一篇文章達到本測試相關門檻的比例。MRR@10 看第一篇相關文章在前十名的位置；nDCG@10 綜合前十名排序。MLQA／MIRACL 採二元相關性；ACORD 保留 0–4 等級，nDCG 使用 2^grade−1，Top-1 則以 grade≥1 判定。未標註文件在公式中沒有相關性增益，但不表示人工判定它不相關。綜合 nDCG 混合不同標註方式，僅供描述性總覽，不能解讀成跨領域的絕對準確率。

哪些資料納入，哪些沒有？

第一批使用完整 MLQA validation 三方向（504、504、1,148題）及 ACORD test 57題，六配置共13,278筆；第二批 MIRACL dev 各選200題，三配置共1,200筆。2,613 是資料集內唯一題目數，不是去除跨語對齊後的獨立問題數。MLQA 包含舊版每方向100題，因此不是完全未見過的 holdout。MIRACL 文章庫是所有 dev 已標註段落的去重聯集（中文3,786、英文7,921篇），不是完整維基語料；Recall@50=100% 只適用於這個子集。QASPER、pilot、失敗與中斷的 attempts 均不納入。

區間如何解讀？

逐題配對 bootstrap 共2,000次、seed 20261023；MLQA 以原始 passage 群聚，ACORD 以 parent query，MIRACL 每題一個 cluster。這不是文章層級群聚，且未作多重比較校正。4B 相對0.6B重排的 nDCG 差異，在三個MLQA與兩個MIRACL分項的95%區間高於零；ACORD 跨零。MIRACL 的 Top-1 差異兩方向皆跨零。ACORD 的 Qwen 4B embedding 候選 Recall@50 僅22.39%、標註覆蓋15.89%，重排無法找回候選池外的相關條款；低分不能全部歸因於重排器。首頁綜合平均沒有另算信賴區間，不能套用分項區間或把所有測量列當成獨立樣本。

速度與容量的實測範圍

Apple M3 Ultra、256 GiB統一記憶體、Metal全層offload；Q8_0、llama.cpp build883 commit1fd20a7f4、context8192、單一parallel slot、rerank k=50。總時間為 warmed query 的 embedding、exact搜尋與重排時間相加，包含沿用同一embedding cache的分項時間；不含載入、建索引、網路、佇列及production併發。沒有獨立30題×3次延遲重測。容量僅為GGUF檔案加總，沒有尖峰RAM/VRAM或其他硬體速度實測。

與公開測量一致嗎？本次補上什麼？

Qwen 官方報告已測量多尺寸 embedding／reranker 的跨任務品質；較大的重排器通常取得較高整體分數。本次六分項中4B重排器的nDCG點估計均高於0.6B，方向相符。新增的價值是固定Q8_0、llama.cpp／Metal、相同Top50候選下，同時呈現容量、延遲與分項差異。MIRACL中文0.6B沒有明確收益、ACORD的Top-1與nDCG排序不同，是值得驗證的本機觀察，並非已證明普遍成立或世界首次。

官方評測與本次觀察對照

大重排器通常較準，這是已有研究的趨勢

Qwen 官方早已報告：4B 重排器在英文、中文及多語檢索平均分數均高於 0.6B。本測試補充的是固定 Qwen 4B 檢索器、Top50 候選與本機 Q8 設定下的品質與耗時，不宣稱首次發現模型放大的效益。

Qwen3 Embedding official release, 5 June 2025 · Qwen3-Reranker-0.6B official model card

升級 4B 的價值，取決於檢索方向與你在意的指標

在本次 MLQA，0.6B→4B 重排使中文查英文 Top1 增加 5.75 個百分點，英文查英文只增加 1.66 點；ACORD Top1 則下降 1.75 點，但 nDCG 上升。六分項的耗時中位數約增為 5.2–5.8 倍。這是本設定的選型線索，不是所有題目都受益的保證。

Qwen3 Embedding technical report, v1

MIRACL 是標註段落子集測試，不能當作完整排行榜

官方 MIRACL 英文與中文語料分別約 3,289 萬與 493 萬段；本測試只在 dev 已標註段落的聯集中搜尋，分別為 7,921 與 3,786 段、各 200 題。分數適合比較這個候選環境內的配置，不能與完整語料榜單比高低。Qwen 訓練資料列有 MIRACL，因此也不能稱為未見過資料集的泛化測試。

MIRACL official project repository · Qwen3 Embedding technical report, v1

ACORD 要看分級品質，且本頁指標與原論文定義不同

本頁 ACORD Top1 採 grade>0（2星以上），包括「同類但僅供參考」條款；原論文將3–5星視為相關。本頁 nDCG 使用 2^grade−1，原論文使用線性 grade；本頁 P@5 固定除以5，原論文高星 P@5 另按可用條款數正規化。因此只比較本頁同一規則下的模型，不把數字當成官方 ACORD 分數的復現。
