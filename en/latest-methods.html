METHODS / OCTOBER 26 MATRIX

How the test works—and what it can establish.

28 setups, six conditions and 73,164 accepted measurements. Definitions, verification scope and downloadable evidence are documented here.

How is the homepage average calculated?

Average all query scores within each condition, then give the six condition means equal weight 1/6. MLQA contributes 50%, MIRACL 33.33% and ACORD 16.67%. This is a descriptive comparison, not an estimate of production traffic. All 28 setups complete every condition; no missing cells are filled with zero. The 2,613 count is unique within datasets, not cross-language deduplicated; 73,164 rows are repeated measurements. nDCG combines relevance and rank, not hit probability. Top-1, MRR and Recall measure different aspects.

What does consistent testing mean?

Within each condition, every setup uses identical queries, corpus, relevance judgments and pinned model versions. Each embedder retrieves 50 candidates; its three rerankers receive the same ordered list. Independent verification checks candidate sets and input-order hashes for all 54,873 reranked rows. Different embedders can retrieve different documents; that is part of retrieval performance. Reranking cannot recover documents outside the candidate pool.

Data scope and relevance definitions

MLQA uses fixed validation directions (504/504/1,148 queries), including the earlier 100 per direction; this is not an untouched holdout. ACORD uses 57 test queries and 3,931 clauses. MIRACL uses 200 dev queries per language with the union of all dev-judged passages: 3,786 Chinese and 7,921 English, not the full million-scale corpus. MLQA/MIRACL use binary relevance. ACORD stars minus one map to grades 0–4: Top-1 counts grade>0 (at least 2 stars), nDCG uses gain 2^grade−1 and P@5 divides by 5. The ACORD paper treats 3–5 stars as relevant and uses linear gain, so scores are not directly comparable. Unjudged documents receive zero gain, not a human judgment of irrelevance.

Does first place establish a reliable winner?

No. The 28-setup leaderboard has no global bootstrap intervals or multiplicity correction; 0.7926 versus 0.7917 differs by about 0.0009. These are point estimates on fixed data. Earlier Qwen 4B paired intervals remain on the historical methods page and are not applied to the new matrix. ACORD has only 57 queries and roughly 15–17% candidate judgment coverage, so low scores do not establish general legal capability. Near-equal reranked MIRACL scores do not show that embedders are unimportant on large corpora.

Timing and hardware limits

Apple M3 Ultra, 256 GiB unified memory, macOS 26.7, Q8_0 and all-layer Metal offload; Python 3.12.14, NumPy 2.3.5 and a pinned llama-server binary. Server context is 8192 with one parallel slot and batch/ubatch 4096; inputs including templates must pass a 4096-token preflight without truncation. Query total adds embedding, exact search and reranking stages; cached candidates reuse the original retrieval timings. Models run in separate batches, not a randomized interleaved latency experiment. Background services remained present, with traffic monitored by a guard. Times exclude cold loading, indexing, network, queues and concurrency; this is not a 30-query ×3 stability study. Size is summed GGUF weights, not measured RAM/VRAM.

Published findings and what this matrix adds

Qwen’s official evaluation scores the 4B reranker above 0.6B on MTEB-R, CMTEB-R and MMTEB-R. Each of the seven local embedders shows the same direction in its six-task mean. Qwen uses Top100 candidates from Qwen 0.6B embeddings; here each embedder supplies Top50 with Q8_0/llama.cpp/Metal, so scores cannot be subtracted directly. The added value is the complete 28-setup comparison: small embedders with large rerankers approach leading quality; larger embedders do not always improve the reranked overall mean; legal and encyclopedia tasks favor different setups. These are local observations, not first-ever discoveries or universal rules.

Verification findings and documentation errata

Independent recomputation of 73,164 rows, 168 summaries and 957,516 quality values found exact quality agreement; input-order hashes were also checked for all 54,873 reranked rows. One runner-generated report sentence says standalone Top100: this is stale wording, while every accepted ranking contains Top50. Source is preserved for traceability; this site corrects the description. MIRACL candidate sets differ across embedders, but candidate Recall@50 is already 99.75–100%, allowing the same reranker to put the same document first. This limits discrimination within the subset; it does not indicate reused results or universal embedder equivalence.
