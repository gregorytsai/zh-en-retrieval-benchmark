Model background and Oct 22 historical results

MODEL / EMBEDDER

BGE-M3

A multilingual embedding model that also supports sparse weights and multi-vector retrieval. This benchmark uses only its single-vector dense retrieval mode.

77.67%Mean standalone Top-1
8.14 msMean query + search time
0.591 GiBTested Q8_0 weights

When is it worth considering?

No task prefix is required, making the input format straightforward. It delivers competitive results with short query latency in this run.

Sparse retrieval, ColBERT-style multi-vector retrieval and hybrid search were not tested. These results do not represent every BGE-M3 capability.
