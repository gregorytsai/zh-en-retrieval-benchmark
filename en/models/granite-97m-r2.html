Model background and Oct 22 historical results

MODEL / EMBEDDER

Granite Embedding 97M Multilingual R2

A compact multilingual embedding model from IBM. It uses ModernBERT, pruning and distillation to produce 384-dimensional vectors.

65.67%Mean standalone Top-1
4.12 msMean query + search time
0.107 GiBTested Q8_0 weights

When is it worth considering?

The smallest weight file and shortest mean query time in this run. Consider it when compute cost and response time take priority.

Lower Top-1 in this run means a quality trade-off for the resource savings. Reranker pairings were not tested. Do not assume that the 97M model supports the MRL features of the 311M version.
