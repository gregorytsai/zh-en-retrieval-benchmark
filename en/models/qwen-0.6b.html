MODEL / EMBEDDER

Qwen3-Embedding-0.6B

A smaller multilingual embedder in the Qwen family. It maps queries and documents into vectors to retrieve a set of potentially relevant passages.

74.67%Mean standalone Top-1
12.78 msMean query + search time
0.595 GiBTested Q8_0 weights

When is it worth considering?

Supports task instructions and reduced embedding dimensions. A separate reranker lets you tune the balance between quality and compute.

Only Q8_0, 1,024 dimensions and a fixed English retrieval instruction were tested. Reduced dimensions were not evaluated. Compare standalone and reranked results separately.
