Model background and Oct 22 historical results

MODEL / EMBEDDER

EmbeddingGemma 2

A compact multilingual embedding model from Google. This benchmark uses only the text component to map queries and documents into a shared 768-dimensional space.

76.33%Mean standalone Top-1
11.31 msMean query + search time
0.289 GiBTested Q8_0 weights

When is it worth considering?

The text component has only 270M parameters. Official support for reduced vector dimensions and selectively loaded multimodal components allows deployments to fit different needs.

Images, audio, video and reduced vector dimensions were not tested. Official Hugging Face inference guidance recommends BF16/FP32 and avoiding FP16; this is not direct evidence of a problem with the Q8_0 setup tested here. Also consult the official usage-policy guidance before deployment.
