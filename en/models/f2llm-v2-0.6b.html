Model background and Oct 22 historical results

MODEL / EMBEDDER

F2LLM-v2-0.6B

An instruction-based multilingual embedding model from CodeFuse, built on Qwen3. Its training emphasizes medium- and low-resource languages.

78.00%Mean standalone Top-1
12.89 msMean query + search time
0.596 GiBTested Q8_0 weights

When is it worth considering?

Competitive average standalone Top-1 across the three directions among the smaller tested models. The project also publishes training data and code.

Only standalone retrieval was tested, with no reranker pairings. Untested pairs cannot be presented as measured recommendations. This run used a community-converted Q8_0 GGUF.
