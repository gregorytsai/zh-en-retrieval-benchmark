Sharing the materials: preserve attribution

The official MLQA repository states that the data comes from Wikipedia and is licensed under CC BY-SA 3.0. The MTEB retrieval dataset card lists the same license. Sharing and adaptation require attribution, a license link, an indication of changes and the same license for adapted material.

Attribution: Patrick Lewis, Barlas Oguz, Ruty Rinott, Sebastian Riedel, Holger Schwenk, MTEB contributors and Wikipedia contributors. Paper: MLQA: Evaluating Cross-lingual Extractive Question Answering（ACL 2020）.

Original Parquet files are preserved. Fixed-seed samples are also converted to JSON with retrieval results and Chinese editorial notes. Original queries and passages are not rewritten. Individual retrieval examples are no longer displayed on the site; full records remain downloadable. These materials and notes are shared under CC BY-SA 3.0, without implying endorsement by the original authors.

Most titles in the upstream retrieval corpus are empty, and per-passage Wikipedia URLs are not supplied. We preserve the provided IDs and fields without inventing individual source URLs. See the dataset NOTICE and license legal code.

Reproduce: verify files before rerunning models

git clone https://github.com/gregorytsai/zh-en-retrieval-benchmark.git
cd zh-en-retrieval-benchmark
python scripts/verify_release.py
python scripts/build_site.py
python scripts/package_release.py
python scripts/verify_release.py

The verifier reads local files and needs no GPU. Website builds use only the Python standard library. Packaging normalizes text line endings and updates file hashes.

If you need to rerun inference

Download the code package or use research/workspace. Follow the original build guide to prepare Q8_0 weights, compatible llama.cpp and Python dependencies. Verify model SHA-256, pooling, prefixes and GPU offload. The original runner relies on macOS/Unix fcntl and process monitoring; it is not a one-click Windows package.

The main entry point is run_guarded.py. Use a new output directory and a future UTC deadline; do not resume the completed v3 run. v2 files are retained only for pilot selection and budget dependencies, not to add v2 results to the ranking.

cd research/workspace/embedding-study-20261022
python -m pip install -r requirements.txt
# Configure weights, data and runtime following BUILD_GUIDE_ZH_TW.md
python run_guarded.py --output run-NEW-ID --deadline FUTURE-UTC-ISO8601

Replace the placeholders in the command above. The original audit_v3.py requires complete attempt and GPU logs. This public release uses scripts/verify_release.py. Public-release and path-change notes (Chinese).

Official sources and further reading

  • Official MLQA dataset and license

    Wikipedia-derived data under CC BY-SA 3.0; code has a separate license.

  • Official MLQARetrieval dataset card

    MTEB retrieval adaptation. The current card lists cc-by-sa-3.0; the archived manifest records the commit used for this run.

  • CC BY-SA 3.0 license summary

    Allows sharing and adaptation with attribution, license retention, change notices and ShareAlike terms.

  • MLQA: Evaluating Cross-lingual Extractive Question Answering

    Lewis et al., ACL 2020. A cross-language extractive question-answering benchmark, not a translation-quality leaderboard.

  • Official Qwen3 Embedding specifications

    Three model sizes, output dimensions, task instructions and Apache-2.0 licensing.

  • Official Qwen3-Reranker-0.6B model card

    0.6B reranker, correct template and relevance-scoring implementation.

  • Official Qwen3-Reranker-4B model card

    4B multilingual reranker, Apache-2.0.

  • Official BGE-M3 model card

    MIT; dense, sparse and multi-vector capabilities, with hybrid retrieval guidance.

  • Official BGE-reranker-v2-m3 model card

    Apache-2.0; multilingual query–document pair scoring.

  • Official EmbeddingGemma 2 model card

    Apache-2.0; 270M text / 740M full multimodal parameters, 768 dimensions, input prefixes and precision guidance.

  • Official F2LLM-v2-0.6B model card

    Apache-2.0; multilingual instruction embeddings, 1,024 dimensions, MRL and query/document formats.

  • Official Granite Embedding 97M Multilingual R2 model card

    Apache-2.0; 97M parameters, 384 dimensions, CLS pooling and ModernBERT.
