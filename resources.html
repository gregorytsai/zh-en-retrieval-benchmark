重現：先驗證檔案，再決定是否重跑模型

git clone https://github.com/gregorytsai/zh-en-retrieval-benchmark.git
cd zh-en-retrieval-benchmark
python scripts/verify_release.py
python scripts/build_site.py
python scripts/package_release.py
python scripts/verify_release.py

驗證程式只讀本地資料，無須 GPU。網站建置只用 Python 標準函式庫；封裝會統一文字換行並更新檔案雜湊。

需要重新推論時

下載程式包或使用 research/workspace。依原建置說明準備 Q8_0 權重、相容 llama.cpp、Python 套件；請核對模型 SHA-256、pooling、prefix、GPU offload。原 runner 依賴 macOS／Unix 的 fcntl 與程序監控，不是 Windows 一鍵執行套件。

正式入口為 run_guarded.py。設定新的輸出目錄與未來 UTC deadline；不要 resume 已完成的 v3。v2 檔案只保留 pilot 選題／預算依賴，沒有把 v2 結果混入排行。

cd research/workspace/embedding-study-20261022
python -m pip install -r requirements.txt
# 先依 BUILD_GUIDE_ZH_TW.md 配置權重、資料與 runtime
python run_guarded.py --output run-NEW-ID --deadline FUTURE-UTC-ISO8601

上面命令含需替換的佔位值。原 audit_v3.py 要完整 attempts／GPU logs 才能執行；公開網站採 scripts/verify_release.py。公開版整理與路徑變更記錄。

官方資料與延伸閱讀

  • MLQA 官方資料集與授權

    資料來自 Wikipedia，資料採 CC BY-SA 3.0；程式授權分開。

  • MLQARetrieval 官方資料卡

    MTEB 檢索版本；現行資料卡標示 cc-by-sa-3.0。本次固定 commit 以封存 manifest 為準。

  • CC BY-SA 3.0 授權條款摘要

    允許分享及改作，需署名、保留授權、標記衍生修改與相同方式分享。

  • MLQA: Evaluating Cross-lingual Extractive Question Answering

    Lewis 等人，ACL 2020；跨語抽取式問答基準，並非翻譯品質排行榜。

  • Qwen3 Embedding 官方規格

    三種模型尺寸、輸出維度、任務提示與 Apache-2.0。

  • Qwen3-Reranker-0.6B 官方模型卡

    0.6B 重排器與正確的模板、相關性分數實作。

  • Qwen3-Reranker-4B 官方模型卡

    4B 多語重排器，Apache-2.0。

  • BGE-M3 官方模型卡

    MIT；dense、sparse、多向量功能與混合檢索建議。

  • BGE-reranker-v2-m3 官方模型卡

    Apache-2.0；多語 query-document 配對評分。

  • EmbeddingGemma 2 官方模型卡

    Apache-2.0；文字 270M、全多模態 740M、768 維；提示與數值精度要求。

  • F2LLM-v2-0.6B 官方模型卡

    Apache-2.0；多語指令向量、1024 維、MRL 與 query/document 格式。

  • Granite Embedding 97M Multilingual R2 官方模型卡

    Apache-2.0；97M、384 維、CLS pooling 與 ModernBERT 架構。
